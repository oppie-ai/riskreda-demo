# Riskreda demo

Static clickable demo for a Swedish AML/KYC assistant for small accounting firms.

Working name: **Riskreda**. Other names still under consideration include Vera, Rely, Kredo, Klientreda and less direct brand names.

This public demo uses mock data only. It is not connected to Henrik's Mac mini, Obsidian vault, OpenClaw, Hermes, Gmail, or any private runtime state.
